# 纯文字领读、知识沉淀与反向调优

适用于本 Vault 中已选正式论文的互动阅读、学习笔记整理及流程复盘。每日发现、下载与 Zotero 交付继续使用 Skill 的资产流程；每日自动化不能替用户完成课堂或提前编造讨论成果。

## 领读工作流

### 1. 恢复目标并准备证据

读取现有笔记、用户明确的基础与偏好以及相关阅读断点。已有目标沿用，不重新访谈；断点只帮助恢复课堂，不能作为论文事实证据。

以 DOI、citekey 和题名核对已有笔记及导入状态中的笔记路径；重新阅读沿用同一篇笔记，不因译名或课程变化新建副本。规范要求应有笔记但当前未找到时，区分资产链路缺口与查找范围不足，检查命名差异和现有记录后再说明结果；“当前未找到”不能证明历史上从未存在。不从 Vault 外测试归档恢复正式资产或历史。

先从正式全文建立讲解依据：研究问题、变量定义、公式条件、假设、训练目标、各数据集用途、实验单位、比较对象和结论范围。需要公开材料补证时遵循现有来源规则。核对相关完整章节、图表与脚注，避免只根据摘要或关键词片段讲解。

首次说明准备学习的主题与可调整的主课数量。可按“问题直觉 → 方法链条 → 数据与训练 → 实验评价 → 用户自己的判断”组织，不固定为五课。基础概念不理解时拆成短课，已经通过的部分可合并。

课时量按模块的学习目标、概念依赖和难度安排，不设统一字数或分钟上限，也不把500—800字或5分钟作为默认配额。“短课”指主题集中、认知负担可控，不要求所有模块等长。

| 模块 | 篇幅与组织方式 |
|---|---|
| 研究问题与动机 | 通常较短，用具体情境讲清研究为什么必要 |
| 方法与公式 | 可较长，按直觉、变量、公式、例子逐层展开；多个依赖概念拆成连续短课，不为长度压缩关键条件 |
| 数据与训练 | 通常中等篇幅，解释数据用途、输入输出、训练与检验的区别 |
| 实验与验证 | 围绕图表、比较条件与证据；熟悉指标不重复教学，基础已掌握的验证内容可合并推进 |
| 论文结论与范围 | 通常较短，讲清作者结论与证据范围，可与已理解的验证内容合并；不替代后面的三个独立收束模块 |

每课结束标准是一个完整学习目标已经讲清，并得到必要理解确认。用户已有回答足以证明理解时不额外设置形式化测验；模块可包含多课，一课也可合并已掌握的相关模块内容，仍须有清楚的共同目标。拆分或合并时更新剩余主课数。

### 2. 一次讲清一个紧密主题

默认中文纯文字。用交通例子建立直觉，再引入论文术语和必要公式；不会影响理解的底层推导留到用户需要时。教学数字明确标注为例子，不与论文阈值或实验结果混写。

概念容易混淆时，先明确“对象、条件、固定量、求解量、事件”。例如概率究竟针对距离、冲突还是碰撞；次数针对独立交互还是相关帧；输出分数与报警阈值分别是什么。简化应保留决定结论的条件。

实验讲解至少交代比较对象、样本筛选、计数单位、阈值来源及验证边界。模型训练、参数/特征选择、阈值校准、独立评估分别追踪；使用另一数据集不能自动替代每一层的独立验证。

### 3. 用反馈判断是否推进

在需要确认理解时，按本课学习目标、独立难点和已有回答决定题数，通常一至三题，但不是固定配额或硬上限。先识别需要确认的关键理解点，再设计能覆盖它们的少量问题；一题不足以覆盖时增加题目或分组讨论，不以一个简单问题代表整课已经掌握，也不按段落机械出题。优先复述、应用、反例与概念区分，不只检验术语记忆；不检验尚未讲清的细节，已有充分回答的知识点不重复考核。

题目明确对象、时间尺度、单位及默认保持相同的条件。同一术语可能指方法类别、行车线路、路段或整程时，直接写明所指；用户作出另一种合理解读时先消除歧义，再判断是否存在知识误解。

逐点反馈：已经理解什么、具体误解在哪、怎样修正。只有影响后续理解的错误才暂停推进，用一个更小的例子和定向问题补讲。通过后继续，不能因回答措辞与预设答案不同而反复加题。正确回答可以说明当前掌握，不代表长期记忆已经验证。

用户问剩余课数时，按已通过主题更新数量；补讲说明属于当前主题的补充，不暗中扩大主课。用户希望更快、更深或暂停时调整节奏。

用户批注逐项回应，使用界面要求的批注索引。中途问题处理后回到当前主题；未提交答案不推定为不理解，明显笔误按上下文解释，不据此设置新关卡。

若先前讲解有误，直接指出并给出证据化更正，不把由讲解引起的误解归咎于用户。已影响持久笔记时同步修正；必要时用一个问题检验修正是否被理解。

### 4. 三个独立收束模块

主课结束后分别引导以下三个模块，不用一组混合的综合题替代，也不由助手独自生成三个栏目。首次规划说明“主课 + 三个收束模块”，汇报剩余量时分开计数。它们按任务目标安排篇幅，没有统一课时限制。

默认依次进行“我形成的理解与判断 → 可引用观点 → 与我当前研究的关系”，每次集中一个模块，等待用户表达后再追问或核验并推进。用户可调整顺序；此前已经针对某模块充分讨论的，提炼现有答案即可，不重复考核。本篇已引导形成的研究联系可以复用，其他未引导栏目不能因此自动视为完成。

| 模块 | 引导重点与示例问题 | 完成标准 |
|---|---|---|
| 我形成的理解与判断 | 先让用户说最重要的收获、最认可或不认可的结果及理由。可问“哪项结果改变了你的看法？依据是哪项实验？”或“你认为复现成本高，具体来自数据、实现还是验证？”追问依据和适用范围，不把个人取舍改写为作者结论 | 用户形成可解释的判断，能够区分论文事实、个人评价与尚未证实的推断；不要求评价必须正面或全面 |
| 可引用观点 | 先问用户希望在自己的论文或综述中用本文支持什么论断、放在哪种论述中，再帮助定位证据、调整措辞和范围。没有明确写作场景时可问“这篇论文有哪些有证据支撑的主张值得引用，为什么？”用户需要帮助时可提供少量候选供其比较，而非直接填满栏目 | 每条选定观点包含可转述的论断、原文位置、证据范围和拟支持的用途；转述与直接引文分开。允许用户认为暂时无可用观点，不能凑数 |
| 与我当前研究的关系 | 围绕实际研究目标、可获取数据和拟采用方法，问“哪些能借鉴？哪些观测条件不满足？直接照搬会在哪里失败？”区分理念借鉴、方法迁移与可执行方案 | 用户明确可借鉴内容及至少相关的必要条件或限制；不把尚未验证的设想写成已完成的数据结论 |

这三个模块是形成观点的讨论，不是连续答题关卡。判断应落到具体证据或条件；引用观点必须能由论文支撑，不能把用户自己的推论归给作者，也不能要求用户独自核验来源。若已有足够表达，Codex负责忠实整理并检查证据，不再要求形式化确认。

用户手动修改、删除或留空的内容体现其当前选择：编辑前重读相关章节，不从旧版本恢复被删除的观点；有疑义先在讨论中厘清，不擅自覆盖。未讨论的栏目可以留空，状态与继续引导事项只记过程文件。用户要求先整理已有部分或跳过模块时按请求交付，不以标准流程强行阻塞。

### 5. 笔记沉淀

用户要求总结时编辑现有笔记，保留已有正确内容，按知识主题组织而不是复制对话。保存必要公式与例子、实验事实、修正后的用户理解及研究判断；将来源章节/图表写在对应内容旁。错误答案不作为用户最终观点保留。

随口提问不自动成为笔记内容或“疑问”。用户明确排除的非核心讨论不收录；若排除会使核心结论失真，用最短方式说明必要条件，不把教学复盘藏进论文正文。已回答问题写入实质章节，无真正未解问题时“疑问”留空。

过程断点、课数、执行历史与提示词复盘放在 `_data/brain` 或现有教学状态文件。学习笔记、独立报告、图谱按用户请求选择，避免重复生成同一知识。逐项核对关键数字、公式方向、样本量、单位和来源，确认没有流程占位语，再交付真实本地链接。

## 反向调优标准流程

触发时机：一篇论文完成领读或笔记交付，或用户明确要求复盘。先完成当前已授权交付，再做简短复盘；已做过且无新反馈时复用记录，不重复生成。每次复盘不等于每次必须改文件。

1. **收集实际证据**：提取用户反馈、重复误解、助手更正、返工和有效做法。只使用真实记录；用户理解得到修正的证据与助手流程缺陷分别记录。无需保存整段聊天。
2. **分类并归因**：区分论文事实、可复用教学规则、长期用户偏好、单次随口问题和工具/数据问题。判断是说明失真、问题歧义、节奏不合适、证据未核验还是数据缺失；不要一律归因于用户基础不足。
3. **选择最小落点**：跨项目任务的本 Vault 约束放 `AGENTS.md`；本地文献流程放本 Skill；详细领读策略放本引用文件；单篇知识放论文笔记；过程与复盘结果放 `_data/brain`。避免同一长规则多处复制。五节课程或某论文公式不固化成通用硬约束。
4. **实施有依据的局部修正**：在已授权范围内修改，不因复盘自动扩展到全局 `teach`、其他技能、定时任务或 Zotero。没有可复用问题则记录“沿用，无需修改”。不同文件冲突时按用户当前要求和项目规则消解；本项目引用路径与手动调用设置保持真实。
5. **用情境验证行为**：检查相关技能格式、引用可达性和上下游规则一致性，再用本次失误或新请求推演预期行为。区分静态检查/情境审阅与实际用户试用，未实测不声称效果提升。下一次真实阅读观察同类问题是否减少，再决定保留、收紧或撤回。
6. **保存并交付结果**：在研究记忆中记录“观察 → 原因 → 修改位置 → 验证 → 下一次观察项”。向用户简短说明采用的改进、改动文件、验证结果和未实测部分。复盘记录不进入论文知识正文，也不冒充正式推送历史。

## 本次领读抽出的验证情境

这些用于审阅流程，不是每篇都要给用户做的测试。

| 触发情境 | 预期行为 |
|---|---|
| 用户说骨架看不懂、只要纯文字 | 从直觉开始短回合领读，不再生成HTML，不直接再发研究者式摘要 |
| 用户把全部满足与至少一次满足混淆 | 明确概率事件，用小样本例子补讲，通过后回到主线 |
| 用户质疑频率尺度或指标适用范围 | 先核对原公式和假设；若是助手简化失真，明确更正并同步后续理解 |
| 用户把另一数据集测试等同阈值独立验证 | 分别标出训练模型、选择阈值和报告效果所用数据，不笼统说“已泛化” |
| 用户说某问题随口一问、不写笔记 | 响应排除要求，不自动创建永久疑问，不复制进最终总结 |
| 用户只要求把所学写入现有笔记 | 更新正确知识与用户判断，保留已有内容；不额外创建报告、图谱或写Zotero |
| 重读同一论文，笔记译名或路径不明显 | 先核对 DOI、citekey、题名及导入路径，复用同一篇笔记；未找到只说明当前核查结果，不推断历史上未存在 |
| 一课包含多个独立难点，但只问了一个容易的问题 | 按学习目标检查覆盖，必要时增题或分组；不固定一题，也不把通常一至三题当作硬上限 |
| “路线”等词被理解为不同对象 | 明确方法类别与行车线路、路段与整程的区别，不把题目歧义直接归因于用户不理解 |
| 主课结束，但个人判断与引用观点未单独形成 | 分别引导三个收束模块，复用已有研究联系，不用助手总结代替用户观点 |
| 用户手动删除引用观点、补充个人评价 | 重读当前文件，保护修改，不自动恢复删除内容；通过相应模块讨论再沉淀 |
| 阅读结束但没有新的可复用问题 | 完成轻量复盘并沿用既有规则，不为流程形式增加提示词 |
